> **什么是信标**：项目里「以它为准」的锚点。每个信标都是一句可执行的判断——
> 看到数字对不上、口径打架、不知道该读哪份时，按信标回源，不靠记忆、不靠推断。
>
> 用法：先看速查表定位，再按需读对应条目。**不需要全读**，只读命中项。

## 二、逐个说明

### B-01 · 工程根

- **名称**：工程根目录
- **用途**：所有相对路径的基准；确认自己在哪个仓库里干活
- **适用场景**：新会话第一件事；路径解析异常时
- **注意事项**：`D:/YourProject` 是 git 仓库，但**工作树 ≠ 提交**——`git status` 长期有大量未提交改动，代码与设定以工作树为准，不看提交历史

### B-02 · 版本号

- **名称**：版本基线与快照
- **用途**：判断"现在是哪个版本"，避免拿旧快照当现状
- **适用场景**：写文档、报版本、对比历史
- **注意事项**：**只认两处**——`project.godot` 的 `config/version`（代码 `A0.0025`）、`VERSION.md`（快照 `A0.0022`、设定 `A0.0029`）。`DELIVERY.md` 里的 `A0.00xx` 是**资产批次前缀**，不是版本号

### B-03 · 设定主源

- **名称**：设定唯一权威台账
- **用途**：查任何编码、ID、主题、文件归属
- **适用场景**：涉及玩法、数值、系统、世界观的任何判断
- **注意事项**：按索引表取，**别整包读**。运行数值以 `data/*.json` 为准，设定解释以 Markdown 为准，两者分工不能混

### B-04 · 尺度合同

- **名称**：视觉与尺度硬规格
- **用途**：画布尺寸、角色占比、锚点、碰撞半径的唯一依据
- **适用场景**：美术生产、UI 布局、场景搭建
- **注意事项**：96×96 画布、12 FPS、8 向、脚底锚点 `(48,94)`、1600×900 里角色占高 12–16%。碰撞半径 10px **只是占位**，物理体积与可见轮廓要分别登记

### B-05 · 投影冻结

- **名称**：投影参数冻结页
- **用途**：确认当前投影 ID，防止各线各画一套
- **适用场景**：新增场景、换视角、导入外部素材
- **注意事项**：当前为 `topdown_3q_ortho_50`。**要改投影必须新开决策并重跑样张**，不能单方面调整

### B-06 · 决策记录

- **名称**：历史决策库
- **用途**：查"当时为什么这么定"、避免推翻已裁决的事
- **适用场景**：口径冲突、方案反复、有人提议改规则
- **注意事项**：路径在 Vault `05-决策记录/`，356 条。新增或修改后**必须**把正文追加到 `<handover-ledger>`。历史记录不改写，只追加更正或替代

### B-07 · 资产总账

- **名称**：全量资产清点结果
- **用途**：判断某件资产在不在、多少字节、什么状态
- **适用场景**：资产盘点、验收、判断"这个文件是不是新的"
- **注意事项**：2026-11-17 口径——在盘 **12,017 件 / 9.43 GB**，**已签收 0**、未验收 4488、在制 7524、作废 5、缺失 30。「已签收 0」是事实：全项目没有一件资产有 G0–G4 验收记录，**别把「生成成功」「文件存在」当验收**

### B-08 · R5 计划

- **名称**：R5 垂直切片计划
- **用途**：知道下一步该做什么、谁做、依赖什么
- **适用场景**：派活前、排期、判断"能不能开始"
- **注意事项**：含 N1–N10 十个节点，**N3 起有前置依赖**。当前该做 N1（八环节基线实测）和 N2（物品三账对账）。**先读它，不要重新规划**

### B-09 · 进度记录

- **名称**：逐轮进度流水
- **用途**：知道"上一轮做到哪、下一轮从哪接"
- **适用场景**：每轮开工前必读；写交接时引用
- **注意事项**：**只追加、不覆盖**。不是计划，是事实记录——计划和实际不符时，以它为准

### B-10 · 记忆索引

- **名称**：Agent 的项目索引
- **用途**：Agent 每轮开工前自动注入的"项目底图"
- **适用场景**：Agent 派活、对话问答
- **注意事项**：**这个文件不在 D:/YourProject 下**，在 `<repo>\.data\memory\`（MultiAgent 侧）。按 B-01 的相对路径规则会指向不存在的 `D:/YourProject\.data\memory\context.md`，所以必须写绝对路径。**手写文件，会过期**——项目状态变了就要刷，否则 Agent 会自信地讲三天前的状态。当前注入 2480 字，上限 2600

### B-11 · 交接账本

- **名称**：跨 Agent / 跨会话交接记录
- **用途**：换人、换 Agent、停线时把现场讲清楚
- **适用场景**：Codex ↔ WorkBuddy 交接、决策镜像
- **注意事项**：**不写凭据、密钥、认证令牌**。简单问答和未形成长期决策的交流不建镜像

## 三、用信标的三条规矩

1. **数字对不上就回源**，不要在两个二手材料之间互相印证——那只会把同一个错误重复两遍。
2. **信标本身会过期**。读的时候顺手看一眼「最后更新」，超过一周的在答案里标注"可能已过期"。
3. **新增信标要满足两条**：① 它是一句话能说清的"以它为准"；② 它会被反复查。只查一次的东西，写进文档就行，不必立信标。

## 五、维护

|---|---|
| 新增信标 | 出现新的"以它为准"的权威源，且会被反复查 |
