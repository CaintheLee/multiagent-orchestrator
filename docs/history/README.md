# 历史归档

这里放**只读**的历史记录：审计、修复、当时的决策。写法固定，写完不改。

## 规则

1. 文件名：`YYYY-MM-DD-主题.md`（例：`2026-11-17-audit-round4.md`）。
2. 内容只写「当时发生了什么、依据是什么、改了什么」，不写「现在应该怎样」——那是 `CURRENT.md` 的事。
3. 发现旧记录写错了：**不修改原文**，在文末追加：

   ```md
   ---
   ## 后续变更（YYYY-MM-DD）
   原文第 N 条已被推翻：……（原因 + 现在的做法）
   ```

4. 引用历史结论前先回代码确认；历史文档里的行号、函数名、测试数都会过期。
5. 不把历史记录搬来搬去：外部可能已经引用过路径，搬动等于断链。
