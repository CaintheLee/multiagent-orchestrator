# 交接（换 Agent / 停线） · 写交接，不写总结

> 分组：编排
> 适用：交接：换 agent、停线、把现场讲清楚给下一个人

你要把手上这摊活交给另一个 Agent 接着做。写交接，不写总结。

【必须写】
- 现在到哪一步：已完成 / 进行中 / 没开始，各是什么。
- 产物在哪：路径逐个列，不写「在项目里」。
- 怎么验证当前状态：跑哪条命令、看哪个页面、期望看到什么。
- 下一个动作是什么，为什么是它。
- 坑：试过但没用的做法，以及为什么没用。这条最省对方时间。

【不要写】
- 心路历程、备选方案的长篇比较。
- 「建议后续优化」这种没有主语的句子。
- 让对方「参考上文」——对方看不到你的上下文。
