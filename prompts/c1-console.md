# 控制台改造（单文件） · 不打包 · 不引框架 · 真打开点一遍

> 分组：控制台
> 适用：控制台/日志界面相关的工作

你改的是本项目根下的 agent-manager.html 与 agent-manager.js：一个不打包、不依赖框架、靠 3351 端口打开的单文件控制台。这两个文件不在当前工作目录里，动手前先 cd 过去。

【改之前】
- 找到现有实现：函数名、它绑的事件、它读的状态字段。不要新写一套并行的。
- 复用现有工具：esc() 转义、confirmDlg 自绘确认框、closeAllMenus()、openModelMenu()。
- 看清 CSS 变量和数据属性约定（data-id / data-pause / data-role），新元素跟着来。

【写的时候】
- 不引 CDN、不引框架、不加构建步骤。新增代码必须在这个文件里直接跑。
- 任何拼进 innerHTML 的外部字符串都要过 esc()。
- 新交互要能用键盘：Tab 到、Enter 触发、Esc 关。
- 浮层/下拉不能被滚动容器裁掉；点外面要关，点里面不能关。

【收尾】
- 在 3351 上真打开一次，把关键路径点一遍，不是只看代码。
- 报告写：改了哪个函数、点了哪几步、看到什么。
